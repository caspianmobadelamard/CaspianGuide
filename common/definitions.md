# تعاریف
**Definitions**

!!! tip "خلاصه"
    تعاریف اصطلاحات کلیدی در استانداردهای دیگ و مخزن.

---

## A-Z

| اصطلاح | تعریف |
|---|---|
| **MAWP** | Maximum Allowable Working Pressure — بیشینه فشار مجاز |
| **MDMT** | Minimum Design Metal Temperature — کمینه دمای طراحی |
| **PWHT** | Post Weld Heat Treatment — عملیات حرارتی پس از جوش |
| **WPS** | Welding Procedure Specification — دستورالعمل جوش |
| **PQR** | Procedure Qualification Record — مدرک تأیید WPS |
| **WPQ** | Welder Performance Qualification — تأیید جوشکار |
| **NDT** | Non-Destructive Testing — آزمون غیرمخرب |
| **RT** | Radiographic Testing — پرتونگاری |
| **UT** | Ultrasonic Testing — فراصوتی |
| **MT** | Magnetic Testing — ذرات مغناطیسی |
| **PT** | Penetrant Testing — مایعات نافذ |
| **VT** | Visual Testing — چشمی |
| **CA** | Corrosion Allowance — حد خوردگی |
| **LPB** | Low Pressure Boiler — دیگ کم‌فشار |
| **P-Number** | گروه متریال طبق ASME IX |
| **F-Number** | گروه الکترود طبق ASME IX |
| **A-Number** | ترکیب شیمیایی جوش |
| **HAZ** | Heat Affected Zone — منطقه متأثر از حرارت |
| **S-N Curve** | منحنی خستگی |
| **FEA** | Finite Element Analysis — تحلیل اجزای محدود |
