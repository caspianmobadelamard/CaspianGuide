# لوازم و تجهیزات (برای فروش)

**Accessories & Equipment**

!!! tip "خلاصه فروش (۳۰ ثانیه)"
    هر دیگ به تجهیزات جانبی نیاز دارد: مشعل، شیر اطمینان، کنترلرها، پمپ، منبع انبساط، سختی‌گیر. کاسپین تمام این تجهیزات را تأمین می‌کند.

---

## تجهیزات اصلی

### 🔥 مشعل (Burner)

| نوع | سوخت | کاربرد |
|---|---|---|
| Gas Burner | گاز طبیعی | اکثر پروژه‌ها |
| Oil Burner | گازوئیل | مناطق بدون گاز |
| Dual Fuel | گاز + گازوئیل | پشتیبان |
| Heavy Oil | مازوت | صنعتی |
| Solid Fuel | زغال، چوب | خاص |

### 🛡️ شیر اطمینان (Safety Valve)

| مشخصه | مقدار |
|---|---|
| استاندارد | ISO 4126-1 |
| تنظیم | ≤ MAWP |
| باز شدن | ≤ 1.1 × MAWP |
| جنس | برنز، فولاد |

### 📊 کنترلرها

| کنترلر | انگلیسی | کاربرد |
|---|---|---|
| پرشر کنترل | Pressure Controller | کنترل فشار |
| ترموستات | Thermostat | کنترل دما |
| اکوستات | Aquastat | کنترل دمای آب |
| لول کنترل | Level Controller | کنترل سطح آب |

### 💧 پمپ و تجهیزات آب

| تجهیز | انگلیسی | کاربرد |
|---|---|---|
| پمپ تغذیه | Feedwater Pump | تامین آب دیگ |
| پمپ سیرکولاسیون | Circulation Pump | گردش آب |
| سختی‌گیر | Softener | حذف سختی |
| دی‌اریتور | Deaerator | حذف اکسیژن |
| منبع انبساط | Expansion Tank | جبران حجم |

### 🌬️ تجهیزات جانبی

| تجهیز | انگلیسی | کاربرد |
|---|---|---|
| ایرسپراتور | Air Separator | حذف هوا |
| فیلتر شنی | Sand Filter | فیلتر آب |
| فیلتر کربن | Carbon Filter | حذف کلر |
| مخزن کندانس | Condensate Tank | جمع‌آوری کندانس |
| سوپرهیتر | Superheater | افزایش دمای بخار |

---

## جدول انتخاب سریع

| نیاز مشتری | تجهیزات پیشنهادی |
|---|---|
| دیگ بخار | مشعل + شیر اطمینان + لول کنترل + پمپ + سختی‌گیر |
| دیگ آبگرم | مشعل + ترموستات + منبع انبساط + پمپ |
| دیگ روغن داغ | مشعل + پمپ + مخزن انبساط + کنترلر دما |
| سیستم کامل | پکیج کامل با نصب |
