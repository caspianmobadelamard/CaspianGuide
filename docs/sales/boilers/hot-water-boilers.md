# دیگ آبگرم و آب داغ

**Warm Water & Hot Water Boilers**

!!! tip "خلاصه فروش (۳۰ ثانیه)"
    دیگ‌های آبگرم برای گرمایش ساختمان (زیر ۱۰۰°C) و دیگ‌های آب داغ برای گرمایش صنعتی (تا ۱۲۰°C) استفاده می‌شوند. استاندارد اصلی دیگ آبگرم **BS 855 / ISIRI 7911** است و در صورت درخواست مشتری، با استاندارد **EN 12953 / INSO 22156** هم قابل ارائه است.

---

## تفاوت دیگ آبگرم و آب داغ

| مورد | دیگ آبگرم | دیگ آب داغ |
|---|---|---|
| **دما** | زیر ۱۰۰°C | تا ۱۲۰°C یا بیشتر |
| **فشار** | اتمسفر یا کم | تحت فشار |
| **کاربرد** | گرمایش ساختمان | گرمایش صنعتی |
| **استاندارد اصلی** | BS 855 / ISIRI 7911 | INSO 22156 / EN 12953 |
| **استاندارد جایگزین** | INSO 22156 / EN 12953 (در صورت درخواست) | BS 855 (برای ظرفیت کم) |
| **ظرفیت** | ۱۰۰,۰۰۰ – ۲,۵۰۰,۰۰۰ kcal/h | ۱۰۰,۰۰۰ – ۲,۵۰۰,۰۰۰ kcal/h |

## مدل‌های دیگ آبگرم

### ۱. دیگ سه‌پاس (Three-Pass)

| مشخصه | مقدار |
|---|---|
| ظرفیت | ۱۰۰,۰۰۰ – ۲,۵۰۰,۰۰۰ kcal/h |
| دما | < ۱۰۰°C |
| فشار | اتمسفر |
| سوخت | گاز، گازوئیل، مازوت |
| استاندارد اصلی | BS 855 / ISIRI 7911 |
| استاندارد جایگزین | INSO 22156 / EN 12953 |

### ۲. دیگ شعله برگشتی (Reverse Flame)

| مشخصه | مقدار |
|---|---|
| ظرفیت | ۱۰۰,۰۰۰ – ۱,۰۰۰,۰۰۰ kcal/h |
| دما | < ۱۰۰°C |
| مزیت | جمع‌وجور، مناسب فضای محدود |

> 💡 **نکته:** مدل Reverse Flame فقط برای **دیگ آبگرم** تولید می‌شود، نه دیگ بخار.

### ۳. پکیج موتورخانه‌ای (Central Heating Package)

شامل:
- دیگ
- مشعل
- پمپ
- منبع انبساط
- کنترلر

## لوازم جانبی دیگ آبگرم / آب داغ

| قطعه | انگلیسی | کاربرد |
|---|---|---|
| شیر رفت | Supply Valve | ورود آب گرم به مدار |
| شیر برگشت | Return Valve | برگشت آب سرد |
| شیر اطمینان | Safety Valve | تخلیه فشار اضافی |
| ترمومانومتر | Thermomanometer | نمایش دما و فشار |
| ترموستات | Thermostat | کنترل دما |
| اکوستات | Aquastat | کنترل دمای آب |
| شیر تخلیه | Drain Valve | تخلیه آب و رسوب |
| مشعل | Burner | تولید حرارت |
| منبع انبساط | Expansion Tank | جبران حجم آب |
| ایرسپراتور | Air Separator | حذف هوا |
| پمپ سیرکولاسیون | Circulation Pump | گردش آب |
