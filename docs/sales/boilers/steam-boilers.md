# دیگ بخار

**Steam Boilers**

!!! tip "خلاصه فروش (۳۰ ثانیه)"
    دیگ بخار کاسپین مبدل آمارد در ظرفیت‌های ۱ تا ۲۵ تن بر ساعت، فشار ۳ تا ۲۰ بار، بر اساس استاندارد INSO 22156 / EN 12953 تولید می‌شود. مناسب صنایع غذایی، دارویی، نساجی و شیمیایی.

---

## مدل‌های دیگ بخار

### ۱. دیگ بخار افقی سه‌پاس (Horizontal Three-Pass)

| مشخصه | مقدار |
|---|---|
| ظرفیت | **۱ تا ۲۵ ton/hr** |
| فشار | ۳ تا ۲۰ bar |
| دما | اشباع |
| سوخت | گاز، گازوئیل، مازوت |
| استاندارد | INSO 22156 / EN 12953 |
| راندمان | تا ۹۲٪ |

**مزایا:**
- راندمان بالا
- احتراق کامل
- عمر طولانی
- نگهداری آسان

### ۲. دیگ بخار فایرباکس (Firebox)

| مشخصه | مقدار |
|---|---|
| ظرفیت | **۱ تا ۱۰ ton/hr** |
| فشار | ۳ تا ۱۰ bar |
| سوخت | مایع، گاز، جامد |
| استاندارد | INSO 22156 / EN 12953 |

---

## اجزای دیگ بخار

- **پوسته** (Shell) — استوانه‌ای
- **کوره** (Furnace) — پاس اول
- **لوله‌های دود** (Smoke Tubes) — پاس دوم و سوم
- **صفحه لوله** (Tube Plate)
- **محفظه برگشتی** (Reversal Chamber)
- **شیر اطمینان** (Safety Valve)
- **پرشر کنترل** (Pressure Controller)
- **لول کنترل** (Level Controller)
- **آب‌نما** (Water Level Gauge)
- **مشعل** (Burner)
- **پمپ تغذیه** (Feedwater Pump)

## جداول انتخاب سریع

| ظرفیت (ton/hr) | فشار (bar) | مدل پیشنهادی |
|---|---|---|
| ۱ - ۳ | ۳ - ۱۰ | Three-Pass |

> ⚠️ **نکته:** دیگ بخار شعله برگشتی (Reverse Flame) **در سبد محصولات کاسپین برای دیگ بخار نیست**. این مدل فقط برای دیگ آبگرم/آب داغ تولید می‌شود.
