# استاندارد ISO 3834

**کیفیت جوشکاری ذوبی مواد فلزی**

!!! tip "خلاصه"
    ISO 3834 یک استاندارد بین‌المللی برای **الزامات کیفی جوشکاری ذوبی (Fusion Welding)** است. کاسپین مبدل آمارد دارای این گواهی‌نامه است.

---

## معرفی استاندارد

**ISO 3834** استانداردی است که الزامات کیفی برای جوشکاری ذوبی (Fusion Welding) مواد فلزی را تعیین می‌کند. این استاندارد مکمل تخصصی **ISO 9001** برای فرآیند جوشکاری است.

**در ایران:** ISO 3834 برای صنایع جوشکاری **اجباری** است.

---

## سطوح استاندارد

| بخش | عنوان | سطح الزامات |
|---|---|---|
| `ISO 3834-1` | معیارهای انتخاب سطح | راهنما |
| `ISO 3834-2` | الزامات کیفی جامع (Comprehensive) | بالاترین |
| `ISO 3834-3` | الزامات کیفی استاندارد (Standard) | متوسط |
| `ISO 3834-4` | الزامات کیفی ابتدایی (Elementary) | پایه |
| `ISO 3834-5` | مدارک لازم برای اعلام انطباق | راهنما |
| `ISO 3834-6` | راهنمای پیاده‌سازی | راهنما |

> **کاسپین مبدل آمارد:** دارای گواهی ISO 3834 سطح **Part 2 (Comprehensive)** — بالاترین سطح.

## الزامات ISO 3834

| # | الزام | توضیح |
|---|---|---|
| ۱ | **بازنگری قرارداد** | بررسی نیازمندی‌های مشتری |
| ۲ | **زیرپیمانکار** | انتخاب و کنترل پیمانکاران جوشکاری |
| ۳ | **پرسنل جوشکاری** | تأیید صلاحیت جوشکار و اپراتور |
| ۴ | **تجهیزات** | مناسب بودن و نگهداری تجهیزات |
| ۵ | **فعالیت‌های تولید** | برنامه‌ریزی، WPS، PQR |
| ۶ | **مواد مصرفی جوش** | کنترل ورود، انبارش، مصرف |
| ۷ | **انبارش قطعات** | جلوگیری از آسیب |
| ۸ | **بازرسی و آزمون** | قبل، حین، بعد از جوش |
| ۹ | **عدم انطباق و اقدام اصلاحی** | مدیریت خطاها |
| ۱۰ | **کالیبراسیون** | تجهیزات اندازه‌گیری |
| ۱۱ | **شناسایی و ردیابی** | ردیابی قطعات |
| ۱۲ | **مستندسازی** | گزارش‌های کیفی |

## ارتباط با سایر استانداردها

| استاندارد | ارتباط |
|---|---|
| **ISO 9001** | مکمل — ISO 3834 تخصصی جوشکاری است |
| **ASME IX** | تأیید WPS/PQR و WPQ |
| **EN 13445** | مخازن تحت فشار — ISO 3834 الزامی |
| **EN 1090** | سازه‌های فولادی — ISO 3834 الزامی |
| **INSO 22156** | استاندارد ملی دیگ‌های پوسته‌ای |

## مزایای گواهی ISO 3834

!!! success "مزایا برای مشتری"
    - ✅ **تضمین کیفیت جوشکاری** — قابل تکرار و قابل ردیابی
    - ✅ **کاهش دوباره‌کاری** — هزینه کمتر
    - ✅ **افزایش عمر تجهیزات** — جوش‌های با کیفیت
    - ✅ **قابلیت صادرات** — پذیرش بین‌المللی
    - ✅ **کاهش ریسک** — جلوگیری از ترک و نشتی

## مستندات الزامی ISO 3834

| مدرک | کاربرد |
|---|---|
| `WPQR` — Welding Procedure Qualification Record | تأیید روش جوش |
| `WPS` — Welding Procedure Specification | دستورالعمل جوش |
| `WPQ` — Welder Performance Qualification | تأیید جوشکار |
| `Weld Map` | نقشه جوش |
| `Weld Log` | ثبت جوش |
| `NDT Reports` | گزارش‌های NDT |
| `PWHT Records` | سوابق عملیات حرارتی |
| `Material Certificates` | گواهی مواد |

## نکات مهم

!!! warning "توجه"
    - **ISO 3834** جایگزین **ASME IX** نمی‌شود — مکمل آن است.
    - برای صادرات به اروپا، این گواهی **الزامی** است.
    - بازنگری دوره‌ای هر ۳ سال توسط مرجع صدور.
    - برای هر پروژه، **Welding Coordinator** (هماهنگ‌کننده جوش) باید تعیین شود.
