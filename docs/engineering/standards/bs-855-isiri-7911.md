# استاندارد BS 855 / ISIRI 7911

**British Standard for Welded Steel Boilers / Iranian Standard for Hot Water Boilers**

!!! tip "خلاصه"
    استاندارد BS 855 (British Standard) و معادل ایرانی آن ISIRI 7911 برای **دیگ‌های آبگرم جوشی کم‌فشار** با ظرفیت تا **۲,۵۰۰,۰۰۰ kcal/h** و فشار کاری تا **۴.۵ bar** استفاده می‌شود.

---

## دامنه کاربرد

| پارامتر | مقدار |
|---|---|
| **نوع دیگ** | دیگ آبگرم جوشی (Welded Steel Boilers) |
| **ظرفیت** | تا ۲,۵۰۰,۰۰۰ kcal/h |
| **فشار کاری** | تا ۴.۵ bar |
| **دمای کاری** | زیر ۱۰۰°C |
| **کاربرد** | گرمایش مرکزی (Central Heating) |

---

## تفاوت با INSO 22156 / EN 12953

| مورد | BS 855 / ISIRI 7911 | INSO 22156 / EN 12953 |
|---|---|---|
| **نسل (Generation)** | قدیمی‌تر (بریتانیایی) | جدیدتر (اروپایی) |
| **دامنه (Scope)** | دیگ‌های ورق جوشی کم‌فشار | دیگ‌های پوسته‌ای |
| **فشار (Pressure)** | تا ۴.۵ bar | تا ۲۰ bar |
| **ظرفیت (Capacity)** | تا ۲,۵۰۰,۰۰۰ kcal/h | نامحدود |
| **پوشش (Coverage)** | ساده‌تر | جامع‌تر |
| **مواد (Materials)** | محدودتر | EN 10028, EN 10216 |
| **جوش (Welding)** | ارجاع کلی | EN/ISO + ASME IX |
| **NDT** | محدود | RT, UT, MT, PT, VT |
| **ایمنی (Safety)** | شیر اطمینان ساده | سیستم‌های محدودکننده |
| **آب (Water)** | توصیه کلی | EN 12953-10 |

## چه زمانی از BS 855 استفاده کنیم؟

✅ مشتری قدیمی که با این استاندارد آشناست
✅ ظرفیت ≤ ۲,۵۰۰,۰۰۰ kcal/h
✅ فشار کاری ≤ ۴.۵ bar
✅ قیمت پایین‌تر مد نظر است
✅ پروژه داخلی بدون نیاز به صادرات

---

## چه زمانی از INSO 22156 / EN 12953 استفاده کنیم؟

✅ مشتری استاندارد جدید می‌خواهد
✅ فشار بالاتر از ۴.۵ bar
✅ صادرات و نیاز به CE
✅ کیفیت بالاتر و مستندسازی کامل
✅ پروژه‌های پتروشیمی و صنعتی

---

## نکته مهم در قرارداد

در **User Design Specification** باید دقیقاً بنویسید:
- کدام استاندارد؟
- کدام ویرایش (Edition)؟
- چه سالی؟

**مثال:**
> Design Standard: **EN 12953-1:2012 to -13:2016**
> or **INSO 22156:1395 (Parts 1-13)**

## پاسخ به مشتری قدیمی

!!! success "پاسخ پیشنهادی"
    «استاندارد BS 855 / ISIRI 7911 برای دیگ‌های کم‌فشار تا ظرفیت ۲,۵۰۰,۰۰۰ kcal/h استفاده می‌شود. این استاندارد برای گرمایش ساختمانی و پروژه‌های داخلی مناسب است. اگر نیاز به **فشار بالاتر از ۴.۵ bar** یا **صادرات** دارید، استاندارد **EN 12953 / INSO 22156** را توصیه می‌کنیم.»
