# گواهی‌نامه‌ها

**Certificates & Accreditations**

!!! tip "خلاصه"
    کاسپین مبدل آمارد دارای گواهی‌نامه‌های معتبر بین‌المللی برای کیفیت و استانداردهای تولید است.

## 🏆 گواهی‌نامه‌های اصلی

### ۱. ISO 3834-2 — کیفیت جوشکاری

| مورد | مقدار |
|---|---|
| **استاندارد** | ISO 3834-2 (Comprehensive) |
| **دامنه** | جوشکاری ذوبی مواد فلزی |
| **اعتبار** | ۳ سال |
| **کاربرد** | دیگ‌ها و مخازن تحت فشار |
| **صفحه مربوطه** | [ISO 3834](iso-3834.md) |

### ۲. ISO 9001 — مدیریت کیفیت

| مورد | مقدار |
|---|---|
| **استاندارد** | ISO 9001:2015 |
| **دامنه** | طراحی و تولید دیگ و مخازن |
| **اعتبار** | ۳ سال |

### ۳. گواهی استاندارد ایران (INSO)

| مورد | مقدار |
|---|---|
| **استاندارد** | INSO 22156 |
| **دامنه** | دیگ‌های پوسته‌ای |
| **مرجع** | سازمان ملی استاندارد ایران |
