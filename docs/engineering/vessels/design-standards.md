# استانداردهای طراحی مخازن تحت فشار
**Pressure Vessel Design Standards**

!!! tip "خلاصه"
    مخازن تحت فشار بر اساس ASME VIII (Div.1 یا Div.2) طراحی می‌شوند. انتخاب بین Div.1 و Div.2 بر اساس فشار، دما و اقتصاد پروژه.

---

## مقایسه ASME VIII Div.1 و Div.2

| معیار | Div.1 (Design by Rule) | Div.2 (Design by Analysis) |
|---|---|---|
| **روش طراحی** | قوانین ساده و محافظه‌کارانه | تحلیل تنش پیشرفته (FEA) |
| **ضریب اطمینان** | بالاتر (3.5 روی UTS) | پایین‌تر (2.4 روی UTS) |
| **ضخامت** | بیشتر | کمتر |
| **هزینه تحلیل** | پایین | بالا |
| **کاربرد** | فشار < 3000 psi | فشار بالا، سیکلیک |
| **بازرسی** | NDT محدود | NDT گسترده |

---

## ساختار ASME VIII Div.1

| بخش | عنوان | کاربرد |
|---|---|---|
| `UG` | General Requirements | الزامات عمومی |
| `UW` | Welded Fabrication | ساخت جوشی |
| `UCS` | Carbon Steel | فولاد کربنی |
| `UHA` | High Alloy | فولاد آلیاژی |
| `UHT` | Heat Treated | عملیات حرارتی |
| `UB` | Bolted Flanges | فلنج پیچی |

---

## ساختار ASME VIII Div.2

| Part | عنوان | کاربرد |
|---|---|---|
| `Part 1` | General Requirements | الزامات عمومی |
| `Part 2` | Responsibilities | مسئولیت‌ها |
| `Part 3` | Materials | متریال |
| `Part 4` | Design by Rule | طراحی با قاعده |
| `Part 5` | Design by Analysis | طراحی با تحلیل |
| `Part 6` | Fabrication | ساخت |
| `Part 7` | Inspection | بازرسی |
| `Part 8` | Pressure Testing | تست فشار |
| `Part 9` | Overpressure Protection | حفاظت فشار |

## مراجع مرتبط

- `ASME BPVC Section II` — متریال
- `ASME BPVC Section V` — NDT
- `ASME BPVC Section IX` — جوشکاری
- `INSO 22156` — دیگ‌های پوسته‌ای
- `EN 13445` — مخازن تحت فشار اروپایی
