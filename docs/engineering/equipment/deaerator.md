# دی‌اریتور
**Deaerator**

!!! tip "خلاصه"
    دی‌اریتور برای حذف اکسیژن و گازهای غیرقابل کندانس از آب تغذیه استفاده می‌شود.

---

## مشخصات

| پارامتر | مقدار |
|---|---|
| **ظرفیت** | 5–200 m³/h |
| **فشار** | 1–5 bar |
| **دما** | 105–130°C |
| **O₂ خروجی** | `≤ 0.005 mg/l` |
