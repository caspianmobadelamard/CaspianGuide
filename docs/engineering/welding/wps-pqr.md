# WPS، PQR و WPQ
**Welding Procedure Specification, Procedure Qualification Record, Welder Performance Qualification**

!!! tip "خلاصه"
    WPS دستورالعمل جوش، PQR مدرک تأیید WPS و WPQ تأیید صلاحیت جوشکار است. همه طبق ASME IX.

---

## WPS (Welding Procedure Specification)

### محتوای WPS

| بخش | QW | اطلاعات |
|---|---|---|
| **Joints** | QW-402 | طراحی اتصال |
| **Base Metals** | QW-403 | P-Number، ضخامت |
| **Filler Metals** | QW-404 | F-Number، A-Number |
| **Positions** | QW-405 | موقعیت |
| **Preheat** | QW-406 | دمای پیش‌گرم |
| **PWHT** | QW-407 | عملیات حرارتی |
| **Gas** | QW-408 | گاز محافظ |
| **Electrical** | QW-409 | جریان، ولتاژ |
| **Technique** | QW-410 | تکنیک |

---

## PQR (Procedure Qualification Record)

### محتوای PQR

- **متغیرهای Essential** (QW-250)
- **متغیرهای Supplementary Essential** (QW-250)
- **متغیرهای Nonessential** (QW-250)
- **نتایج تست** (Tension, Bend, Impact)

### فرم‌ها

| فرم | کاربرد |
|---|---|
| `QW-482` | WPS |
| `QW-483` | PQR |
| `QW-484A` | WPQ Groove |
| `QW-484B` | WPQ Fillet |

---

## WPQ (Welder Performance Qualification)

### تست‌های مورد نیاز

| تست | QW | کاربرد |
|---|---|---|
| **Tension** | QW-150 | استحکام |
| **Bend** | QW-160 | شکل‌پذیری |
| **Impact** | QW-170 | چقرمگی |
| **Fillet** | QW-180 | گوشه‌ای |
| **RT/UT** | QW-191 | جایگزین |

### محدوده تأیید

| پارامتر | محدوده |
|---|---|
| **Thickness** | `2t` (حداکثر) |
| **Position** | طبق جدول QW-461.9 |
| **Diameter** | `≥ 73 mm` |

## SWPS (Standard WPS)

- طبق `ASME IX Article V`
- توسط AWS منتشر می‌شود
- سازمان باید `Demonstration` انجام دهد
