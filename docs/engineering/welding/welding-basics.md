# مبانی جوشکاری
**Welding Basics — ASME IX**

!!! tip "خلاصه"
    جوشکاری مخازن تحت فشار باید طبق ASME IX با WPS تأییدشده، PQR مستند و جوشکار تأییدصلاحیت‌شده انجام شود.

---

## انواع جوش

| نوع | انگلیسی | کاربرد |
|---|---|---|
| **لب به لب** | Butt Weld | اتصال اصلی |
| **گوشه‌ای** | Fillet Weld | اتصال جانبی |
| **شیاری** | Groove Weld | ضخامت بالا |
| **سطحی** | Surfacing | پوشش |

---

## فرایندهای جوشکاری

| کد | نام | کاربرد |
|---|---|---|
| `SMAW` | Shielded Metal Arc Welding | عمومی |
| `GTAW` | Gas Tungsten Arc Welding (TIG) | ریشه |
| `GMAW` | Gas Metal Arc Welding (MIG) | سریع |
| `FCAW` | Flux Cored Arc Welding | ضخیم |
| `SAW` | Submerged Arc Welding | پوسته |
| `PAW` | Plasma Arc Welding | دقیق |

|---|---|---|

---

## عیوب جوش

| عیب | انگلیسی | علت |
|---|---|---|
| **ترک** | Crack | تنش، هیدروژن |
| **تخلخل** | Porosity | گاز محبوس |
| **آخال سرباره** | Slag Inclusion | تمیزکاری ناکافی |
| **عدم نفوذ** | Lack of Penetration | آماده‌سازی نامناسب |
| **عدم ذوب** | Lack of Fusion | انرژی کم |
| **زیربرش** | Undercut | جریان بالا |

---

## الزامات ASME IX

- `QW-100` تا `QW-500` — قوانین
- `QW-200` — تأیید WPS
- `QW-300` — تأیید جوشکار
- `QW-400` — داده‌ها
- `QW-500` — SWPS
