# جوش لوله به صفحه
**Tube-to-Tubesheet Welding**

!!! tip "خلاصه"
    جوش لوله به صفحه لوله، حیاتی‌ترین اتصال در مبدل‌های حرارتی است. باید طبق ASME VIII و IX انجام شود.

---

## انواع اتصال

| نوع | توضیح | کاربرد |
|---|---|---|
| **Expanded** | منبسط شده | فشار پایین |
| **Welded** | جوشی | فشار بالا |
| **Expanded + Welded** | ترکیبی | استاندارد |
| **Explosive** | انفجاری | آلیاژی |
